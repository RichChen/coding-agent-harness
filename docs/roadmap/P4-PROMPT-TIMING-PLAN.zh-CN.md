## 1. 问题与结论边界

比较同费用约束下的原策略、开始时行动提示、中途半费用预算行动提示，观察有限预算尝试的交付质量、额外修改风险、验证与收尾及成本。首次编辑时间仅为过程指标，不把更早编辑或更少读取直接解释为改善。

线上无法知道模型是否读到了正确文件或已理解根因。中途触发使用事先可观察的预算节点，不使用 gold patch、未来轨迹、隐藏评分、事后正确位置或主持人的答案判断。允许模型认为证据不足；不能强迫猜补丁。

此前 T23 的两次提示响应与宿主回放仅支持检查点敏感性。本轮为新的完整任务比较，不重跑 M8、T23 或 Sphinx-8721，不重新实现 A/B，不新增循环检测、记忆平台或多模型求解系统，不修改生产默认行为。

## 2. 拟比较条件

| 条件 ID | 行为 |
| --- | --- |
| N | 原任务与原求解策略，加本轮共同费用准入/停止规则，不附加行动提示 |
| I | 第一次请求前，以额外 `role=user` 消息添加行动提示一次 |
| M | 本运行完整 usage 按冻结峰值价格累计结算达到 0.225 元后，处理完该轮工具/原有反馈，原循环仍将发起下一请求时，以同一角色添加同一提示一次 |

主持已采纳共同每运行 0.45 元、最多 24 次模型请求的设计。调用、费用、上下文或时限任何一个先到都正常结束该次有限预算尝试；24 不是已经资助的请求次数。M 的阈值只依据本运行已知 provider usage 的峰值结算，不用预留、历史累计或缓存优惠实扣。0.225 元是先导选择，不是已证明最优阈值。

初稿固定 24/M12 设计已保存在 `D:/crq/artifacts/p4-prompt-timing-20261031-01/design-initial-24-m12.zh-CN.md`，相应协议/fixture 保留历史身份。本 v2 改为费用中点，属于动态部署策略比较；具体触发轮数由先前行为和输入/输出消耗决定，不能继续称为固定第 13 次请求或调用进度中点。

M 不以“没有编辑”或“已读正确文件”为额外条件。原循环已自然结束或因预算/错误停止的任务不因提示重新唤醒，仍计入所属策略的结果；达到节点但未发出下一请求也记录为未暴露。提示不得单独增加一次求解调用或重置任何账本。

若跨阈值的响应没有工具调用，但原 `workspace_controller.check` 产生合法失败反馈并继续循环，则尚未自然结束，M 仍可在原本的下一请求前插入。I/M 均只在持久历史中新增一条提示消息，后续依共同上下文规则保留，不每轮重复追加；需同时核验持久历史、压缩后的模型视图与实际请求。反馈续答、预算拒绝和正常结束分别记录。

拟冻结提示沿用已诊断的英文原文，不加入定位或答案：

> Using only the information already available, submit the smallest change you can justify and verify. If the evidence is insufficient, state the specific missing evidence rather than guessing.

这句话在任务开始时可能导致过早编辑或报告证据不足并结束，这些是要观察的策略结果，不因效果不佳现场改词。I/M 只改变插入时间，提示文本、角色及可见性生命周期必须清楚记录；不把“开头 system 规则”与“中途 user 消息”混成纯时机比较。

比较对象是部署策略；插入时点自然改变信息阶段、新近性、可见轮数和累计输入长度，本轮不声称分离了这些机制。N 不加入占位提示。插入位置为原任务或完整上一轮工具/宿主反馈之后、该次唯一倒计时之前。分别记录提示准备、最终准入、外部请求发送、响应已知；发送但响应未知者标为尝试送达/结果未知，不能记成未暴露。最终准入与请求留证必须涵盖提示、倒计时、完整原生 tools 和输出预留，不将中间 `context.prepared` 视图误称为最终请求。

三组使用相同任务字节、基点、镜像、工具原生顺序、模型/思考模式/采样设置、masking、倒计时、验证/反馈限额和最终预留。保留当前完整入口的候选与验证控制；所有偏离此前 P4 的共同参数均显式记录，不把旧运行当本轮对照。

## 3. 选题与预检

目标为 2 道新任务 × 3 条件 × 每条件 1 次完整尝试，共 6 次先导运行；这是可行性与逐题行为比较，不支持稳定修复率差异或显著性结论。任务须在运行前选定，不按求解结果换题、增样或挑选成功轨迹。

优先使用现有固定 Sphinx 镜像和受支持基点。A 从公开 issue/需求及公开源码准备候选，不读取 gold patch、隐藏测试或历史解题答案。可只读核对历史任务 ID 清单来标注是否使用过；不能把对本轮新选称为从未见过的 held-out。若同一基点没有两个合格任务，报告具体缺口，不悄悄换环境、注入人工 bug 或把同一问题拆成两题。

每题须交付公开来源、任务原文与字节 SHA、基点适用性、允许修改范围、模型可见材料、冻结公开检查及身份、原始基点的真实行为失败与正向对照。构建/依赖/导入错误不是目标失败。检查要有保持原有功能的对照，避免“全部禁用”获得通过。

## 4. 预算与资源

原累计求解 API 峰值无缓存估算为 **1.837572 元**，原总额度 **5 元**，算术差额 **3.162428 元**；非账户账单实扣，不含开发和审查会话费用。本次不增加总额度。

B 必须依据当前价格和实际准入/预留实现，给出逐调用、逐运行、整组三条件及整轮的保守核算；不得用过去约 0.4 元的实测均值当成六轮安全上限，也不得依赖缓存折扣或提前成功才放得下。每次发送前，已知费用、未结预留及本次完整保守预留之和不得超过该运行 0.45 元。预留方法必须覆盖最终请求的消息、tools、倒计时、提示及输出，不能将 bytes/4 估计当 provider token 上界。主持依据最终两题尺寸和独立准入审查，选择共同输出 2048、原 64000 最终准入窗口、按完整保序 SDK 请求字节加协议余量计算动态预留，作为下一实现阶段的参数；正常原生账本继续有效。这是设计参数选择，动态预留的持久化和实际执行配置尚未实现/冻结。

预留定义：`Uj = 完整 SDK 请求 UTF8 字节数 + 512 + 32 × 消息数 + 128 × 原生工具数`，`Rj = (2Uj + 8 × 2048) / 1000000` 元。该方法是保守规划代理，不是 provider tokenizer 上界。实际 usage 超包络照实结算并停批，未知调用保留全额预留；不给某组额外缩减输出或历史来保证送达。最终两题首请求均可准入，中等合成历史存在条件执行窗口，大历史仍可能拒绝；真实 M 可达性未知。

设计演变：独立初查指出，若承诺六运行均资助 24 次且每响应允许 4096 token，仅最大输出就为 `6 × 24 × 4096 × 8 / 1000000 = 4.718592 元`，超出余量。主持经 B 的预算设计与 Astra 追加审查后，采用每运行独立费用上限，避免为凑次数大幅削窄上下文；不要求所有限制同时跑满。

v2 分配：每题完整 N/I/M 预占 1.35 元，两题共 2.70 元；历史加新分配为 4.537572 元，原总额内未分配余量 0.462428 元。每运行未使用金额不转给其他组，不追加样本；异常余量仅应对已发生的不确定暴露，不提高某组限额。费用是冻结价格下的保守规划，不是供应商账户硬封顶。

一次结算可能从阈值以下跳到只剩少量余额，M 即使达到阈值也可能因下一次完整预留不足而未送达；此时正常记录预算截断，不能借钱或只缩小 M 的输出。离线须核对等于阈值、跨阈值后无可用请求、提示增加输入导致拒绝、自然结束不唤醒、合法反馈续答、24 次先到、未知用量和组间不可借钱。还需用真实初始请求与合法代表性历史核对该费用策略确有可执行的提示后窗口；预算算术成立本身不等于适合检验提示效果。

模型 alias/fingerprint、完整 usage、零重试和未知用量停批要求保持。已发出的未知调用保留预留，不能当作免费失败重试。模型映射、价格或 fingerprint 与冻结条件变化时停止并记录，不跨版本合并三组效果。

准备阶段不调用求解 API、不新增 probe。仅 A 持有本轮本地 Docker 预检执行权，使用现有镜像、独占 owner 标记及新输出目录；不得操作其他轮资源。B 和 Astra 不启动 Docker/GPU。主持人是未来付费启动及预算汇总的唯一负责人。

## 5. 观测与分析

- 主要交付维度：冻结公开目标检查、既有回归、候选证据完整性；额外修改的依据和风险单独审查，不能以测试绿色代替。
- 自主行为：模型是否发起复现/验证，是否根据结果修正，是否自然收尾。宿主最终检查和封存不计为模型自主验证或完成。
- 效率：实际模型请求/工具调用、首次源码编辑、首次可核验有效修改（无法确定时记未知）、输入输出 token、保守费用、耗时、停止原因。
- 所有任务按分配条件报告；M 未触发、提前结束、无补丁、错误和预算截断均保留。小样本不计算夸大的百分比收益。
- 运行顺序在结果出现前冻结，尽量平衡时间顺序；两题无法完全平衡三条件的位置，报告残余限制。temperature=0 不保证确定性。
- 审查者先按匿名候选 ID 做质量审查，再解盲条件；若无法做到或已经见过映射，明确报告实际盲法状态。

额外修改使用逐 hunk 审查表：公开需求依据、必要性的证据、受影响原有行为、退化/兼容性风险、固定检查覆盖。判为必要、合理但证据不足、明显无关或有害；不能用行数少或检查绿色替代。按事前统一规则需要补充的检查单列为探索性结果，不改冻结主验收口径。
