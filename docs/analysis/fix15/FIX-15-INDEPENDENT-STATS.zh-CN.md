## 任务级模式

按每道题两次运行的解出次数，N 比 U-new 更高的题有 6 道，更低的题有 3 道，21 道相同。E-new 比 N 更高的题有 3 道，更低的题有 2 道，25 道相同。N 的提升主要来自 holoviz、keras、pytest-dev、researchobject 等题。E-new 相对 N 的净变化很小，主要是 mpmath 和 packit 的改善抵消了 graphistry 与 tox 的下降。

## 费用和行为

- 每解出一次的平均费用约为 U-new 0.795 元、N 0.425 元、E-new 0.300 元。
- N 与 U-new 的配对平均模型调用差为 −22.1 次，E-new 与 N 的配对平均差为 −5.9 次。
- N 与 U-new 的编辑率差为 +26.7 个百分点，E-new 与 N 的编辑率差为 +11.7 个百分点。
- 这些费用和调用量是本批次的观察结果。解释上更像是干预减少了重复循环或更快进入编辑阶段，但当前数据没有把“减少调用”单独设计成因果因素。

## 能回答的问题

- **“只加一句下一步提示是否改善找到后不编辑？”** 在本批次中，N 相对 U-new 的编辑率上升 26.7 个百分点，解出率上升 10.0 个百分点。配对方向与假设一致，但精确 McNemar p=0.180，区间仍包含 0，因此结果支持“可能有帮助”，还不足以把效应当成稳定定论。
- **“完整结果解释是否比简单下一步提示更有效？”** E-new 相对 N 的解出率只上升 1.7 个百分点，编辑率上升 11.7 个百分点。解出结果没有显示明确的额外收益。
- **“是否减少了重复循环和成本？”** E-new、N 的平均调用和费用低于 U-new，方向稳定。由于三组提示内容同时改变了模型的下一步行为，当前实验不能把成本差归因于某一个内部机制。

## 证据边界

- 这是 30 道固定题、单一模型、每题两次重复的同批次比较。它回答的是该题集和该模型上的行为差异。
- 运行中的一次账本恢复和一次候选快照重试没有改变任务配置，但应在正式报告中保留。
- 结果不能证明 harness 限制在一般模型或其他题集上必然造成同样幅度的影响，也不能证明提示是唯一机制。
