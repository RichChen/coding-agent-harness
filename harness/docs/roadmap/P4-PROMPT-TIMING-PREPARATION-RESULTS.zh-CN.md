## 4. 预算尺寸支持什么

拟议六次比较为两题各 N/I/M 一次。每次独立分配 0.45 元、最多 24 次请求；M 在本次已知 usage 按冻结峰值价格结算达到 0.225 元后，原流程仍将继续的下一请求前插入。没有编辑与否、是否读到正确文件都不是触发条件。

主持已依据独立复核选择共同输出 2048、原 64000 最终准入窗口，作为后续实现参数，记录在 `selected-design-v2.json`。输入预留依据完整最终 SDK 请求：`U = UTF8 字节数 + 512 + 32 × 消息数 + 128 × 工具数`，`R = (2U + 8O) / 1000000` 元。发送前需 `S + held + R <= 0.45`。这是保守规划代理，不是实测 token 或 tokenizer 上界；异常用量照实记录并停批。动态 R 的实际持久化实现仍待完成。

| 任务 | 无提示初始预留 | 开始提示初始预留 | 2048 / 64000 最终准入 |
| --- | ---: | ---: | --- |
| 8637 v2 | 0.053362 元 | 0.053866 元 | 均通过 |
| 8800 v1 | 0.043650 元 | 0.044154 元 | 均通过 |

B 的最终证据有 32 条尺寸记录和 80 个费用条件点（8 个初始、72 个合成历史费用点）。四个 4000 / 8000 字符观察的合成历史，在假设 `held=0`、`S=0.225 / 0.26 / 0.30` 时，两题的 N/M 都通过上下文和费用两道检查；四个 12000 字符观察在 2048 输出下均上下文溢出，8637 v2 于 S=0.30 还预留不足。1024 的完整对照另存。

第二个实际审查发现是合成请求初版只有尺寸/哈希摘要，无法精确独立重建。主持要求 B 补交离线生成器；Astra 随后独立重建全部 32 条 SDK 请求、80 个费用点和 12 组汇总，零差异，并另行解析完整正文核对任务、工具顺序、参数、消息配对、倒计时、准入和费用。原报告 SHA 保持不变。独立运行的临时原始报告由主持按原 SHA 复制归档为 `host-archived-independent-admission-reproduction-v2.json`，不改写审查者原始来源。

这说明存在条件可执行窗口，不证明真实轨迹可达、提示会触发、2048 足够生成任意补丁或一定有下一请求。实际运行还受调用、时间、自然结束、完成控制等限制。提示未送达必须报告，不能据此声称提示无效，也不能只比较成功送达者。

六运行规划 2.70 元，历史峰值估算 1.837572 元，合计 4.537572 元；原 5 元内未分配异常余量 0.462428 元。组间不借用、不补样。本阶段新增求解费为 0，历史估算未变化；非供应商账单实扣，也不含开发/审查会话费用。

## 5. 当前没有完成的内容

准备验收不等于运行入口验收。现有薄包装复用正常 AgentLoop、RunSession、SDK 和持久事件，但控制器/工具使用离线替身；固定费用状态也仍是内存原型。

后续最小实现包是：按最终请求计算并持久化预留、完整 usage 结算及未知停批；接通实际 Workspace CompletionController、原验证限额、候选 capture/seal/export 和任务检查交接；验证实际模型身份、异常停止与清理，最后冻结可执行配置/脚本/任务/价格/检查清单。仍由主持分派单一实现者和独立审查，沿用已有 A/B，不增加模块。

协议中的“响应已知”与“响应可执行”应分开：length 响应可以已知计费，但不能执行截断工具；原型并未完成生产模型身份校验。最终多运行调度的 known-length 口径也需冻结，不能从 mock 原型推断已实现。

评价仍以目标验收、回归、逐 hunk 额外修改风险、自主验证与自然收尾、费用为主。两题各一次只是先导；不能推出稳定修复率差异，也不能称为排除了新近性、可见轮数和输入长度的纯时机效应。
